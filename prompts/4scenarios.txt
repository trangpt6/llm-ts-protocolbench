Scenario 1:
The forecasting setup is strictly defined as follows:
  - Forecasting type: One-step ahead prediction
  - Forecasting strategy: Static setup
  - Training scheme: The model is trained once on the training dataset and subsequently applied recursively over the entire test set
  - Forecast horizon: 1 (one-step ahead forecasting)
  - Use of ground truth during inference: Disabled (no updates using true values after each prediction)
  - Model retraining: Not performed during the forecasting process

Scenario 2:
The forecasting setup is strictly defined as follows:
  - Forecasting type: One-step ahead prediction
  - Forecasting strategy: Rolling update
  - Training scheme: The model is retrained at every time step
  - Forecast horizon: 1 (one-step ahead forecasting)
  - Use of ground truth during inference: Enabled (update the model with the true value after each prediction)
  - Model retraining: Performed during the forecasting process (retrain after each prediction step)

Scenario 3:
The forecasting setup is strictly defined as follows:
  - Forecasting type: Multi-step ahead prediction
  - Forecasting strategy: Rolling update
  - Training scheme: The model is retrained at every time step
  - Forecast horizon: H (>0) (forecast multiple steps ahead per prediction step)
  - Window advancement: 1 time step per iteration (the window slides by 1, not by H)
  - Use of ground truth during inference: Enabled (update the model with the true values after each prediction step)
  - Model retraining: Performed during the forecasting process (retrain after each prediction step)

Scenario 4:
The forecasting setup is strictly defined as follows:
  - Forecasting type: Multi-step ahead prediction
  - Forecasting strategy: Block-wise rolling update
  - Training scheme: The model is trained on each block and retrained after each block
  - Block size: B (>0) (forecast multiple steps ahead within each block)
  - Forecast horizon: B (forecast multiple steps ahead in each block)
  - Use of ground truth during inference: Enabled (update the model with the true values after each block)
  - Model retraining: Performed during the forecasting process (retrain after each block)
